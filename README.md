🍽️ Bhojnam
Bhojnam is a modern food discovery web application built using React.  
It allows users to browse, search, and explore restaurants in a clean and responsive interface.

🚀 Features
- 🔍 Search restaurants by name
- ⭐ Filter restaurants by rating
- ⚡ Fast and responsive UI
- 🧭 Client-side routing using React Router
- 💅 Styled using pure CSS
- 📦 Bundled with Parcel
